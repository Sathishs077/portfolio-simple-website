# 🌐 Personal Portfolio Website

A simple personal portfolio website built using HTML and CSS. This project includes a Home page to introduce myself and a Contact page to provide contact information.

## ✨ Pages

- 🏠 **Home** – A personal introduction and portfolio landing page.
- 📩 **Contact** – A page for visitors to find my contact information.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://sathishs077.github.io/portfolio-simple-website/

   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📁 Project Structure

```text
portfolio/
├── index.html
├── contact.html
└── style.css
```

## 🎯 Purpose

This project was created to practice my HTML and CSS skills and build my first personal portfolio website.
